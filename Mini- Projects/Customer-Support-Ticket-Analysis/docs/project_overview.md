# Customer Support Ticket Analysis

## Business context
A fictional support team wants to monitor ticket volume, response and resolution times, agent workload, customer satisfaction, and unresolved work.

## Tables
- `customers`: fictional customer segments.
- `agents`: support agents and teams.
- `tickets`: issue category, priority, channel, status, and timestamps.
- `ticket_feedback`: optional 1-to-5 satisfaction ratings.

## Analysis
Ticket KPIs, resolution and response duration, agent workload, satisfaction, monthly changes, and above-average resolution times.

## Limitations
Small fictional dataset. Resolution analysis excludes tickets without a resolution timestamp. Feedback is optional. Agent comparisons should account for ticket difficulty and assignment differences.
